# Acoustic-Visual-Break-In-Detector
This is my group project for SKEE 1103 C PROGRAMMING FOR ENGINEER final assignment themed Security and Safety. I was assigned to write and implement the code for our Acoustic Visual Break-In Detector device. 

This device serves as an security monitor that utilises vibration and sound sensors to detect physical tampering against structural barriers such as door and windows. When physical impacts are detected, it produces an alarm sound to draw attention. The owner then can deactivate the alarm with registered NFC card. In addition, to accommodate multi-user environments like households, the system supports registering up to 10 unique NFC cards. Besides, when monitoring is unnecessary, owner can disarm the device so any external impact would not trigger the alarm. Finally, to further minimize false positives, the sensitivity thresholds of the sensors can be dynamically adjusted via the provided user interface.
